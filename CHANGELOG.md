# Changelog

## Unreleased

### Added
- The ClickHouse driver: `clickhouse.Open(dsn)`, `clickhouse.Driver(dsn)`, `clickhouse.OpenDB(db)`.
  DML through mutations (`ALTER TABLE … UPDATE`, lightweight `DELETE`, `mutations_sync=2`),
  ids generated by the driver (`orm.IDGenerator`), DDL for MergeTree tables with table
  options and data-skipping indexes; constraints and transactions fail with clear errors.
- DDL golden test, DML and id tests; integration test on the shared `orm/drivertest`
  suite (`drivertest.SQLWith`, `-tags integration`), CI with ClickHouse in services.
